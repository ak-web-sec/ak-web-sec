# AKWEBSEC

Official website for [AKWEBSEC](https://akwebsec.co.za) — cybersecurity and secure development for South African businesses.

## About

AKWEBSEC provides penetration testing, security monitoring, and secure development services for South African SMEs. All services are POPIA-aligned and priced in ZAR.

## Services

- **Penetration Testing** — Manual web application, API, and infrastructure testing with actionable reports
- **Security Monitoring** — Continuous automated vulnerability scanning, SSL monitoring, and uptime checks
- **Secure Development** — Security-first website and mobile app development

## Tech Stack

- Static HTML5 / CSS3 / Vanilla JavaScript

- Formspree form handling
