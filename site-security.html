Site Security

We eat our own dog food. Here is how we have hardened akwebsec.co.za.

Security Headers

We implement the following security headers on all pages of this site:

Strict-Transport-Security: max-age=31536000; includeSubDomains
Enforces HTTPS across all subdomains for one year.
X-Frame-Options: DENY
Prevents clickjacking by disallowing framing.
X-Content-Type-Options: nosniff
Prevents MIME-type sniffing attacks.
Referrer-Policy: strict-origin-when-cross-origin
Limits referrer information on cross-origin requests.
Permissions-Policy: geolocation=(), microphone=(), camera=()
Disables unnecessary browser features.

Content Security Policy

Our CSP restricts resource loading to trusted sources:

default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'; frame-ancestors 'none'; base-uri 'self';

Infrastructure

  • Hosted on GitHub Pages with Cloudflare CDN
  • DNSSEC enabled
  • Automatic HTTPS/TLS 1.3
  • No server-side processing or databases (static site = minimal attack surface)
